# Bloei

Bijvriendelijke tuinen, daken en terreinen — voor burgers én bedrijven. Zonder gif, met inheemse planten, het hele jaar door.

## Live

De site is een statische one-pager en staat live via **GitHub Pages**:

**https://bbsolutions-hosting-freemiumapps.github.io/bloei-website/**

## Structuur

- `index.html` — de volledige pagina (NL)
- `styles.css` — design system (Fraunces + Space Grotesk + Space Mono, cream/ink/honey)
- `script.js` — interacties: menu, reveals, counters, accordion, seizoens-tabs, formulier
- `favicon.svg` / `og-image.svg` — icon en social image
- `.nojekyll` — schakelt Jekyll uit voor GitHub Pages

Geen build-stap, geen dependencies — gewoon pushen naar `main` en Pages serveert de site.
